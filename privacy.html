Privacy & data controls

Updated 2026-11-01 · About · spider-seo.app

Spider SEO Chrome companion has one purpose: auditing SEO, analytics, consent and performance on pages you explicitly choose. We use information only to provide these features and comply with the Chrome Web Store User Data Policy, including its Limited Use requirements.

What is read

When you start inspection or request a test from a paired local app/MCP, the extension reads selected-page URLs, titles, descriptions, headings, canonical links and language, heading outline, image/link counts, hreflang, JSON-LD types/parse errors and observed navigation/resource/paint/LCP/CLS timings; supported tag identifiers, event names, request endpoint/status and consent flags; and known banner visibility. It does not collect general browsing history, form inputs, passwords, cookie values or arbitrary analytics event/user properties. Website content and event names may nevertheless contain personal information.

Observed browser timing is limited to buffered entries available for the current selected navigation; it is not a Lighthouse score or field-data report. Manual Send page report transfers these diagnostics to the paired local app/MCP when you choose it. Run full test combines page inspection, a 10-second analytics capture and Lighthouse; if paired, that action also sends the combined report to your local app/MCP automatically. Without pairing the report stays locally in Chrome.

Local Lighthouse reloads the requested page, reads its resources and rendered content through Chrome’s debugger, and produces a report with URLs, performance measurements and audit findings. Reports may include snippets of page content and screenshot thumbnails. Your existing site session/storage is preserved. Page requests go to the sites/resources that the page normally loads.

The optional complete Lighthouse mode asks the paired desktop app to run Lighthouse in a separate clean Chrome session. It does not use the selected tab’s cookies. The resulting report is returned to the extension and local app/MCP.

Storage and deletion

Inspection results stay in Chrome’s in-memory session storage, limited to 1,000 observations per recording tab and one latest Lighthouse report plus one latest combined test report. They disappear when Chrome’s session ends. Clear events deletes a timeline; Delete session results stops all captures and clears stored reports. Closing a tab removes its timeline. Selected workspace, Lighthouse device and engine preferences are stored locally between sessions. Pairing credentials stay locally in your Chrome profile until Disconnect or uninstall; they are not synced to a Google account.

Optional local app and MCP

Pairing is off by default. Entering the code explicitly enables the Spider SEO app and its MCP on this Mac to open requested URLs and receive audit results. Communication is authenticated and limited to 127.0.0.1:47836. The native broker keeps results in memory for approximately 15 minutes, with bounded job history. Disconnect revokes the token; the app also offers Disconnect. Results returned to an MCP client can be transmitted by that client to its chosen AI provider under that client’s policy. We do not choose or operate that provider.

The extension sends no browsing or report data to Spider SEO servers, Google Analytics, advertising services or data brokers. No data is sold, used for ads, credit decisions or unrelated profiling; the developer does not receive or read your reports. A page itself may send its own analytics requests, which this extension observes without modifying. Opening the website or exporting/sharing a report is a separate user action. Exported files remain until you delete them.

Your choices

You can use standalone inspection without pairing; grant/revoke site access and debugger permission in Chrome’s extension settings; stop capture; clear session results; disconnect; and uninstall. Lighthouse and local automation have visible controls and indicators. No third-party code is downloaded at runtime.

For support and the public privacy policy, visit spider-seo.app/privacy. The website’s published policy must include this extension before Chrome Web Store submission.
